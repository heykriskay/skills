About

These are the skills I use every day. Some I wrote myself, others I adapted from open-source sets and trimmed to fit how I work.

Claude asks questions until the idea is clear, writes a spec, plans small test-first tasks, builds them one commit at a time, and writes the PR. I approve the spec, the plan and every commit. In between, it keeps going on its own.

Install

As a plugin, inside Claude Code:

/plugin install kriskay-skills --marketplace heykriskay/skills

Or copy the files, to also get the rules and status line:

git clone https://github.com/heykriskay/skills.git
cd skills && ./install.sh

The skills

grillingAsks questions until the idea is clear.
to-specWrites a design doc and waits for your OK.
to-planSplits the spec into small test-first tasks.
execute-planBuilds task by task, one commit each.
test-driven-developmentA failing test before any code.
systematic-debuggingFind the cause before fixing.
verification-before-completionNo "done" without running the check.
review-sinceReviews changes against standards and the spec.
commitProposes a message, commits after your OK.
prWrites the PR description.
handoffSaves progress for a new session.
